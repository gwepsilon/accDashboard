# accDashboard

Accessibility compliance dashboard (local development). React + Vite + TypeScript.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite dev server on port 5173 |
| `npm run build` | Production build |
| `npm run lint` | Oxlint |
| `npm run preview` | Serve the production build |

## Cloud Agents

Repository-managed environment: `.cursor/environment.json` runs `scripts/cloud-agent-install.sh` on install and starts `npm run dev` in a terminal.
